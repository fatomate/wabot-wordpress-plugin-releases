# Wabot WordPress Plugin Releases

Public, installable releases for **Wabot - WhatsApp Notifications**.

This repository contains production release notes and ZIP installers only. The private source code, tests, internal reports, and development files are not published here.

## Installation

1. Open the latest release.
2. Download `wabot-whatsapp-notifications.zip`.
3. In WordPress, go to **Plugins > Add New Plugin > Upload Plugin**.
4. Upload the ZIP and activate **Wabot - WhatsApp Notifications**.

The ZIP always uses the canonical root folder `wabot-whatsapp/` so an update replaces the existing standalone plugin instead of creating a second copy.
